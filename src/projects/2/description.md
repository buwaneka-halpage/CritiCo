### 📚 Language Institute Management System

A **web-based management system** developed using **PHP** to streamline the daily operations of a language institute. The platform provides administrators with a centralized dashboard to manage students, courses, finances, and schedules efficiently.

The system features an **interactive dashboard** that visualizes key data such as monthly income, expenses, and student statistics using dynamic charts. Administrators can quickly monitor financial performance and track active, paid, and inactive students.

It also includes a **course calendar** that allows staff to view weekly or monthly class schedules, helping manage different language classes and instructor sessions with ease.

Additional functionalities include **student management, payment tracking, financial reporting, and schedule organization**, making the platform a complete solution for small to medium-sized education institutes.

This project demonstrates my ability to build **full-stack web applications using PHP**, design **data-driven dashboards**, and create **user-friendly administrative interfaces** for real-world business workflows.

**Key Features**

* Financial dashboard with income and expense analytics
* Student activity and payment tracking
* Interactive course scheduling calendar
* Monthly reporting system
* Responsive admin interface for efficient management

**Tech Stack**

* PHP
* JavaScript
* HTML / CSS
* Chart libraries for data visualization
* MySQL database
